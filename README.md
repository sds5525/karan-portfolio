# Karan S Achar — Portfolio

Single-file site: open `index.html` in a browser, or upload the folder to any static host
(Netlify, Vercel, GitHub Pages, Cloudflare Pages).

Pages (hash routes): `#home` landing, `#work` disc carousel, `#project-one` ... `#project-six` project pages.

To edit content, open `index.html` and change the `P=[ ... ]` array in the script (titles, roles, years, tools, descriptions).
The MASALA preloader logo is embedded as a base64 PNG (`LOGOIMG`).
